# microbial-ecology-analysis

Reproducible analysis workflows and code for microbial ecology research.

## Paper index

- [2024 coastal 16S/18S analysis](papers/2024-coastal-16S-18S/README.md) — public in-house scripts, configuration templates, provenance records, and release checks for the associated amplicon study.

Each paper is maintained in its own versioned subdirectory so that additional
papers can be added without mixing analysis contracts or interpretation rules.

## Public-release scope

This repository contains author-owned scripts, configuration templates, and
provenance documentation. Raw sequencing data, processed ASV tables, sample
metadata, reference databases, generated figures/tables, binaries, and local
machine-specific files are intentionally excluded. See each paper directory
for its exact input/output contract and limitations.
