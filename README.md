# microbial-ecology-analysis

Reproducible analysis workflows and code for microbial ecology research.

## Paper index

- [KSS-18S — V5.13](KSS-18S/README.md) — minimal Python/R numerical workflows and the selected processed KSS-18S, Coastal and EukBank inputs used by this study.
- [2024 coastal 16S/18S analysis](papers/2024-coastal-16S-18S/README.md) — public in-house scripts, configuration templates, provenance records, and release checks for the associated amplicon study.

Each paper is maintained in its own versioned subdirectory so that additional
papers can be added without mixing analysis contracts or interpretation rules.

## Public-release scope

This repository contains author-owned scripts, configuration templates, and
provenance documentation. Release scope is study-specific. `KSS-18S/` additionally
contains explicitly selected processed count tables, metadata and compact
reference results, with provenance and third-party attribution. This exception
does not change the earlier Coastal code-only release. Raw sequencing data,
complete reference databases, manuscripts, binaries and local machine-specific
files are excluded. See each study directory for its exact contract and limits.
