# Provenance boundary

The files in this directory document the public code release without
redistributing private or processed study data.

Included records describe software versions, execution sessions, analysis
parameters, external-input requirements, and explicit exclusions. They do not
constitute a copy of the study metadata, ASV tables, reference databases, or
generated results.

The public SHA-256 manifest is generated after sanitization. Re-run
`validation/check_public_script_release_v1.py --check` after any local change.
